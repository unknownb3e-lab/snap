# SnapTube - Clone

موقع + تطبيق PWA لتنزيل الفيديوهات والأغاني مع تصميم داكن فخم وآخر إصدار.

## ✨ الميزات
- تصميم داكن فخم
- جودات تظهر تلقائي حسب الفيديو
- دعم منصات متعددة عبر yt-dlp
- PWA + زر إضافة للشاشة الرئيسية
- سجل تنزيلات محفوظ

## 🚀 النشر على Railway
1. ارفع المجلد على GitHub
2. في Railway اختر New Project → Deploy from GitHub
3. سيتم تثبيت yt-dlp تلقائيًا عبر nixpacks.toml
4. بعد النشر شارك الرابط

## 📱 كتطبيق على الموبايل
افتح الرابط من الموبايل واختر "إضافة إلى الشاشة الرئيسية" أو استخدم PWABuilder.
